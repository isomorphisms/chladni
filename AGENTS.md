# Rectangle kernels

All consumer C, including host tests, must use the ICK source/profile pinned
by the existing Billiard producer. Stock GCC/Clang are not accepted evidence.
Use the existing ai-ci ick-host action; do not build another compiler gate.
The host Makefile delegates compiler checks to that pinned Billiard checkout.

Chladni owns rectangle modes. Billiard owns collisions. The shared adapter
must call both owners, use one immutable rectangle request, and restart its
ray on a changed request. Do not vendor a second copy of either engine.

Keep Dirichlet, simply-supported, and unsupported free-edge labels explicit.
An adjustable ray need not align with a mode component. Four-wave phase
fronts, ray trajectories, and standing nodal sets are distinct objects.
